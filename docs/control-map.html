Unpatched · Security research platform

Product Control Map

A researcher-to-organization vulnerability disclosure platform: programs, scope, reports, triage, bounty decisions, and reputation, built end to end on Supabase/Postgres with a Next.js App Router frontend. This map is reconciled against the actual repository — migrations, RLS, RPCs, services, actions, tests, and every decision document — not against prior status claims.

PRODUCT IMPLEMENTATION COVERAGE · computed from the 06 feature registry below, not a company metric

Researcher

Discover, join, report, evidence, communicate, get decided, build reputation. The strongest, most complete vertical.

Organization

Create programs, define scope, triage, decide, pay out. Complete except automated (non-manual) payout execution.

Platform

A real service-role-only admin tier with operational recovery tooling. No cross-organization moderation exists.

Public

Anonymous landing page and program registry — real, filterable, no login wall on discovery.

Security

RLS everywhere, RPC-only mutation, real TOTP MFA, enumeration-safe auth flows, a 12-char real password minimum.

Infrastructure

A fully real local dev stack. Zero production deployment, cloud project, or SMTP provider exist anywhere.

02 — Researcher journey

From anonymous visitor to paid, reputable researcher

The single most complete path in the product. One real, visible break: there is no retesting mechanism once a report resolves.

03 — Organization journey

From signup to paid resolution

Complete through triage and decision. Payout execution is real but manual — a human confirms the transfer, the ledger never fakes a success.

04 — Platform / security operations

A real platform_admins membership table, granted only by service_role — no in-app self-escalation path exists. Operational recovery is real for the outbox; deliberately read-only for notifications and payments.
